# Hader (حاضر)

An employee attendance and management system that replaces traditional fingerprint devices.
Employees are checked in automatically when they log in from the company network.

## Planned features
- Automatic check-in from the office network, with explicit check-out
- Daily status: early, on time, late, compensated, absent
- Points ledger that rewards early arrival
- Leave and short-departure requests with manager approval
- Attendance correction requests
- Role-based access: Admin/HR, Manager, Employee
- Monthly reports per employee and department

## Tech stack
- C# / .NET 10
- ASP.NET Core Web API
- SQL Server + Entity Framework Core
- JWT authentication
